Introduction

Goal: Detects blog and forum posters whose behavior may create model-provider liability risks (e.g., AI psychosis / “spiralism,” unhealthy AI companionship dynamics, or new jailbreak practices).

Pipeline steps

  • Candidate Discovery: Uses semantic search via Exa.ai to find relevant posts across blogs and forums.
  • Risk Gate: Filters candidates through a small-model risk gate to cheaply remove obvious non-risk content.
  • Case Card Generation: Uses a extraction-model judge to generate structured case cards summarizing behavior and supporting evidence.
  • Canonicalization: Transforms case cards into a canonical schema so entries can be compared consistently.
  • Embedding: Embeds case cards into vector space to enable semantic similarity search.
  • Similarity Routing: Routes semantically similar cards to the novelty evaluation stage.
  • Novelty Evaluation: Uses extraction-model and language-model judges to determine whether a case matches an existing pattern or represents a new one.
  • Pattern Creation: Creates new risk patterns when novel behaviors are detected, including a structured description and risk evaluation.
  • Evaluation: Benchmarks each judge on real and synthetic datasets to select the lowest-cost model and most reliable evaluation prompt for each stage of the pipeline.

How to use this site

  • Check out the Case Cards screen to see cards for each source organized by semantic similarity, then click to inspect linked patterns.
  • The Pipeline Demo screen lets you select a URL with a potentially harmful post and inspect prompts/outputs for each stage.
