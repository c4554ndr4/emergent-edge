Emergent Edge-Case AI Use Detector

Detects blog, forum, and issue-tracker posts whose behavior may create model-provider liability risk, including agent misuse, companion harm, coercive automation, data loss, and tool-chain exploits.

Introduction

Goal: surface edge-case AI use that looks liability-relevant or operationally strange enough to monitor, then convert it into case cards and compare those cards against a deliberate pattern library.

Pipeline steps

  • Candidate Discovery: Uses multiple Exa semantic-search families to find 2026 posts across Reddit, GitHub, forums, blogs, and personal essays.
  • Liability Gate: Uses a small-model risk gate to cheaply remove obvious non-cases.
  • Corpus Worthiness: Uses a stronger curator to keep only testimony, weird incidents, personal essays with concrete stakes, and tested procedural writeups.
  • Case Card Extraction: Uses a extraction-model extractor to generate evidence-first case cards.
  • Canonicalization + Embedding: Turns each case card into retrieval text and embeds it for semantic search.
  • Pattern Fit: Compares each case against a deliberate generic pattern library and decides whether it fits an existing pattern or looks structurally new.

How to use this site

  • Pipeline Demo shows one representative daily run with the real prompts, stage summaries, selected outputs, and raw JSON.
  • Case Cards shows the current curated corpus in semantic space, with pattern cards placed at the center of the clusters they represent.
