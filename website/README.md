# Case browser

Static case library for [Emergent Edge](https://emergent-edge-case-ai-use-detector.vercel.app). The deployed files are under `public/`; `vercel.json` preserves the earlier explorer URLs.

The dataset contains edited research summaries, not original source records or independently verified incidents. See the collection information in the site for its limits.

For a local preview, serve `public/` with a static HTTP server. No credentials or model calls are required.
